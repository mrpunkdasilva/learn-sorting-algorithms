# Insertion Sort: Vantagens vs. Desvantagens

## Vantagens:
*   Simples de implementar.
*   Eficiente para pequenos conjuntos de dados.
*   Eficiente para conjuntos de dados que já estão substancialmente ordenados.
*   Mais eficiente na prática do que outros algoritmos quadráticos simples como Bubble Sort e Selection Sort.
*   Estável: mantém a ordem relativa de elementos com chaves iguais.
*   In-place: requer apenas uma quantidade constante O(1) de espaço de memória adicional.

## Desvantagens:
*   Ineficiente para grandes conjuntos de dados.
*   Possui uma complexidade de tempo de pior caso e caso médio de O(n^2), o que o torna impraticável para grandes arrays.
